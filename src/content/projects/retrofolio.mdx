Retrofolio is a portfolio backtester: pick a set of tickers and weights, a date range, and a rebalance schedule, and see how the portfolio would have performed against a benchmark. I built it to satisfy my own curiosity about portfolio theory, and to give myself a non-trivial full-stack project to push on production engineering — security posture, deploy automation, observability — without the surface area of a SaaS.

## Stack

- **Frontend:** Next.js (App Router), React Query, Recharts, Tailwind.
- **Backend:** FastAPI, SQLAlchemy, Alembic migrations, Celery + Redis for async backtests.
- **Data:** Postgres for persistence, yfinance for historical prices (cached so tests don't hit the wire).
- **Infra:** Docker Compose locally, GCP Compute Engine + nginx in production, GitHub Actions for CI/CD, Terraform for the network and VM.
