**Changes:**

- `docs/decisions/0005-astro-6-upgrade.md` — ADR recording the decision, the breaking changes that did and did not apply, migration steps, and budget verification.
- `CLAUDE.md` — updated "Astro 5" → "Astro 6" and corrected the content config path.

**Problems:**
- First attempt: swapped `z` import from `"astro:content"` to `"zod"` to clear the deprecation hints. Failed: `zod` is bundled inside Astro, not a standalone dep, so Vite cannot resolve it from user code. Reverted. The hints are informational; 0 errors, 0 warnings.
- First build attempt without moving `config.ts` produced `LegacyContentConfigError` — Astro 6 requires `src/content.config.ts`.

**Resolution:** `pnpm lint && pnpm check && pnpm build` all green. First-load budget: 33,213 B (was 33,022 B on Astro 5 — +191 B, well under 50,000 B).
