# 0002. Font: Newsreader, weight 400 only, Latin subset, self-hosted

Date: 2026-04-11
Status: Accepted

## Context

The design rules call for a self-hosted variable font subset to Latin, avoiding Geist (overused in 2026) and Inter (dated), with "a bit of character but still readable, possibly a serif." The first-load budget is <50KB total.

## Decision

Self-host **Newsreader** at **weight 400**, Latin subset, as a single static woff2 file in `public/fonts/newsreader-latin-400.woff2`. Downloaded from Fontsource's CDN, committed to the repo, preloaded from `Base.astro`, referenced via `@font-face` in `src/styles/global.css`.

Headings and body use the same weight (400). Visual hierarchy comes from size, letter-spacing, and for `h2` a color drop to `--color-muted`.

A second copy as TTF lives at `scripts/fonts/newsreader-latin-400.ttf`, used only by the build-time OG image generator (satori doesn't parse woff2). Not shipped to users.

## Alternatives considered

- **Fraunces** (variable serif, SOFT + WONK axes). Strong personality, but recognizably trendy on design-leaning personal sites in 2026 and the variable woff2 is ~58KB on its own — over budget.
- **Literata** (variable serif, Google). Safest and most neutral of the three serifs considered; ages best but has the least character.
- **Newsreader variable** (wght axis, Latin subset). First choice until sizing — ~58KB for the variable woff2 blows the 50KB budget on the font file alone.
- **Newsreader 400 + 600 static statics**. Two files, ~40KB combined. Within budget but leaves little headroom for HTML + CSS and commits us to a "headings are bolder" aesthetic that the reference sites (paco.me, leerob.com) don't actually use.

## Consequences

**Easier**:

- 22KB font file. With the ~7KB built HTML (CSS inlined), first-load is ~29KB — 21KB of headroom against the 50KB budget.
- One `@font-face` block, one preload link, one weight — the font story is trivially simple to reason about.
- The on-aesthetic consequence: matches paco.me / leerob.com, where headings are distinguished by size/tracking, not weight.

**Harder**:

- **No bold.** If a future section needs bold emphasis inline (`<strong>`), the browser will synthesize faux-bold, which looks bad in a serif. If that becomes a real need, download a static 600 weight (~20KB), add it as a second `@font-face`, and check the budget.
- **No italic.** `<em>` falls back to faux-italic. Same remediation: add a static italic weight only if needed.
- **Revisit if Newsreader starts feeling generic.** It's Google-hosted and will show up on other sites. The character budget was deliberately chosen to tolerate "calm" over "distinctive" — if David's site starts feeling indistinguishable, this ADR gets superseded with a pickier pick.
